<h3 align="left">⭐ Featured Project</h3>

<h4 align="left">Selenium TestNG Automation Framework — UI, API & Database</h4>

<p align="left">
A modular Java-based automation framework that combines UI automation, REST API testing
and SQL Server database testing in a single Maven project.
</p>

<p align="left"><b>Key Highlights</b></p>

<p align="left">
✅ Selenium WebDriver and Page Object Model<br>
✅ Reusable business Action Layer<br>
✅ REST Assured API automation<br>
✅ POJO-based API request models and JSON payloads<br>
✅ SQL Server connectivity using JDBC<br>
✅ Database CRUD test scenarios<br>
✅ Centralized WebDriver and object management<br>
✅ TestNG listeners, groups and retry support<br>
✅ Extent HTML reporting and Log4j2 logging<br>
✅ Excel and JSON test data management<br>
✅ Centralized configuration and reusable utilities<br>
✅ Separate TestNG suites for UI, API and database tests
</p>
